🔥 Ficha Ígnea

Uma ficha digital de RPG moderna, responsiva e instalável como aplicativo, desenvolvida para jogadores de Dungeons & Dragons e sistemas similares.

📖 Sobre o Projeto

O Ficha Ígnea nasceu da necessidade de ter uma ficha completa, organizada e acessível diretamente pelo celular, sem depender de papel ou apps limitados.

O projeto oferece uma experiência fluida, com armazenamento local, interface otimizada para mobile e diversas funcionalidades avançadas para gerenciamento de personagens.

⚙️ Funcionalidades
👤 Personagem
Criação e edição completa de personagens
Upload de imagem personalizada
Campos como classe, raça, idade, antecedentes e mais
Sistema de aliados
📊 Atributos
FOR, DES, CON, INT, SAB, CAR
Modificadores automáticos
Perícias e salvaguardas
Proficiência e inspiração
⚔️ Combate
Sistema de vida (normal + temporária)
Barra de HP interativa
Classe de armadura (CA)
Deslocamento
Exaustão
Pontos de morte
Resistências
🎒 Inventário
Itens com quantidade e descrição
Sistema de diário integrado
Organização com movimentação de itens
Edição via popup
🔥 Poderes e Magias
Separação entre poderes e magias
Magias organizadas por círculo (0–9)
Sistema de DT automático
Tipos de dano com identificação visual
Sistema de cargas
🧠 Sistema Extra: Estilo (Devil Trigger)
Rank de combate (D → SSS)
Bônus progressivos durante a batalha
Mecânica inspirada em Devil May Cry
